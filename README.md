# A股反转因子回测项目

## 项目目的
验证“过去跌得多的股票未来是否会反弹”这一规律在A股市场是否成立。

## 数据来源
BaoStock，沪深300前50只成分股，2023-2024年日频数据。

## 方法
- 计算20日反转因子
- 按因子值分5组回测
- 计算IC、ICIR、多空组合净值

## 核心结论
- IC均值0.0135，因子方向正确但预测力弱
- 多头组累计净值3.2倍
- 多空组合在2024年Q4普涨行情中回撤，说明因子对市场环境敏感
